| Command | Description |

### 🔐 NV Talk / HeartCipher System
A custom vowel-substitution cipher language with 3 progressive learning grades.

| Grade | Rules |
|---|---|
| **Grade 1 — Beginner** | Vowel swap only: `a→b e→c i→f o→d u→k` · spaces preserved |
| **Grade 2 — Intermediate** | Grade 1 + space→`q` · real-q adjacent to space→`*` |
| **Grade 3 — Advanced (Master)** | Grade 1+2 + Clone & Partner Protection shields |

**Permission hierarchy:** Owner → Scholars (`.grant`) → Students

| Command | Description |
|---|---|
| `.grant / .reject` | Assign or remove Scholar teaching privileges |
| `.teach @user [1/2/3]` | Send formatted grade lesson in group |
| `.nv [text]` | Encode text at Grade 3 (or specify grade) |
| `.nvd [text]` | Decode NV Talk back to English |
| `.quiz @user [grade]` | Start live quiz — bot auto-checks reply |

## 🛠️ Manual Setup

### Prerequisites

- **Node.js** v20 or higher
- **FFmpeg** — for media processing and TTS audio conversion
- **yt-dlp** — for audio/video downloads

```bash
# Install yt-dlp
pip install yt-dlp

# Ubuntu/Debian
sudo apt install ffmpeg

# Termux
pkg install ffmpeg yt-dlp nodejs
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/tinotendadurani55/effective-octo-waffle.git
cd effective-octo-waffle

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env
nano .env

# 4. Start the bot
node index.js
```

On first launch, a QR code or 8-digit pairing code will appear. Scan or enter it in WhatsApp to link your account.

## 🔐 Environment Variables

| Variable | Required | Description |
|---|---|---|
| `SESSION_ID` | ✅ | Base64-encoded WhatsApp session for restarts |
| `OWNER_NUMBER` | ✅ | Your WhatsApp number (digits only, e.g. `263777426534`) |
| `BOT_NAME` | ✅ | Display name of the bot (default: `MINIMA V13`) |
| `OWNER_NAME` | ✅ | Your display name (default: `t.Durani`) |
| `PREFIX` | ✅ | Command prefix (default: `.`) |
| `MODE` | ✅ | `public` or `self` |
| `PORT` | ✅ | Health check port (default: `8000`) |
| `GROQ_API_KEY` | ✅ | Free at [console.groq.com](https://console.groq.com) — powers `.hw` and `.trs` |
| `GEMINI_API_KEY` | ⚡ Recommended | Free at [aistudio.google.com](https://aistudio.google.com) — fallback AI |
| `SESSION_DIR` | Optional | Custom session directory path |

> **Getting API keys:** Both Groq and Gemini are completely free with no credit card required. Groq provides LLaMA 3.3 70B and vision models at 14,400 requests/day free.

## 🏗️ Architecture

```
effective-octo-waffle/
├── index.js          # Core — Baileys connection, all commands, event handlers
├── package.json      # Dependencies and scripts
├── session/          # Encrypted WhatsApp auth state (auto-generated)
├── downloads/        # Temporary media files (auto-purged every 10 min)
└── database.json     # Local JSON persistence (settings, learn DB, NV Talk grants)
```

**Tech Stack**

| Layer | Technology |
|---|---|
| WhatsApp Client | [@whiskeysockets/baileys](https://github.com/WhiskeySockets/Baileys) |
| Runtime | Node.js 20+ (CommonJS) |
| HTTP / Health | Express |
| Media Processing | FFmpeg + yt-dlp |
| AI Primary | Groq (LLaMA 3.3 70B + llama-4-scout vision) |
| AI Fallback | Google Gemini 1.5 Flash |
| Network Toolkit | Native `net` + `tls` + axios |
| Hosting | Koyeb (also supports Termux) |
| Persistence | JSON file (no external DB required) |
