# Kidjustin-k Mini-Pair
Lightweight tool to get Session ID.

## Setup
1. `pkg install nodejs git -y`
2. `git clone <your-repo-link>`
3. `cd <your-repo-name>`
4. `npm install`
5. `node index.js`

## Usage
- Wait for the code to appear.
- Link it on WhatsApp.
- Copy the `Kidjustin-k~...` string from the terminal.
